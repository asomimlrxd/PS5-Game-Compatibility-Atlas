# Changelog

## 0.1.0 — 2026-10-13

- Primeira versão navegável do PS5 Game Compatibility Atlas.
- 83 registos de teste, 46 nomes de jogos/títulos, 18 fontes públicas e 7 guias de formato.
- Pesquisa cruzada e filtros por firmware, formato, armazenamento e estado.
- Relatos contraditórios e testes curtos mantidos separados com nível de evidência.
- Bilingue: português de Portugal e inglês.
- Formulário de contribuições apenas local, com exportação JSON e sem backend.
- Exportação dos registos curados para CSV, incluindo dados de contexto e ligação direta à fonte.

- Documentação de metodologia, contribuição e limites da investigação.
- Testes automáticos de integridade de dados e workflow de validação para GitHub Actions.

## Limitações conhecidas

- A lista comunitária Google Sheets foi localizada, mas a grelha completa não pôde ser verificada através da vista pública indexada; não foram importadas células não verificadas.
- Esta é uma recolha manual inicial, não uma lista exaustiva de todos os jogos, fontes ou versões.
- As contribuições permanecem no navegador; não existe sincronização entre utilizadores nem backend de moderação.
